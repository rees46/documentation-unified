# Категория

Офферы разложены по категориям. Категории офферов могут быть вложены друг в друга. Например, в категории "Товары" могут быть подкатегории "Электроника", "Одежда", "Мебель" и т.д.

Категория может иметь:

- название;
- ссылку на страницу на сайте;
- ссылку на изображение;
- идентификатор самой категории;
- идентификатор родительской категории.
