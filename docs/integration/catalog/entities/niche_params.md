# Нишевые параметры

Это отдельный набор параметров, которые стоит передавать в товарном каталоге для усиления работы алгоритмов. 

Например, если вы передаете `fashion_gender` в офферах с одеждой, алгоритмы будут учитывать эти свойства товаров в сессии покупателя, смогут предположить пол посетителя, даже если он анонимный, и повысить видимость товаров с такими же характеристиками, что увеличит конверсию визита в покупку.
