# Параметры товара

Параметры – перечень характеристик товара, который может участвовать в алгоритмах, а также в формировании автоматического фильтра результатов полного поиска.

Параметры передаются в оффере как список, состоящий из:

1. Названия.
2. Значения.
3. Единицы измерения для числовых параметров.

Примеры параметров:

1. Размер памяти на флешке.
2. Материал ботинок.
3. Размер брюк.
4. И что угодно еще.

Как правило, параметры выводятся в карточке товаров как "Характеристики".
