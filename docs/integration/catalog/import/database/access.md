# Доступ к базе данных

База данных может быть создана как в кластере REES46, так и на стороне клиента. 

Если БД создается на стороне REES46, то обычно логином и паролем выступают [API ключи из личного кабинета в CDP](../../../../guides/settings/api/index.md). Имя базы данных и хост/порт передаются ответственному сотруднику клиента индивидуально.
