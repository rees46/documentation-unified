# Проверка работоспособности

При успешной интеграции в разделе "[Логи импорта каталога](../../../../guides/library/products/index.md)" в личном кабинете будут появляться записи о том, сколько новых товаров найдено, сколько отправлено в обработку, сколько успешно импортировано, а также причины ошибки импорта проблемных товаров.
