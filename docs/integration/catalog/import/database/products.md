# Таблица `products`

Структура таблицы:

| name       | type              | comment                                                                        |
|------------|-------------------|--------------------------------------------------------------------------------|
| id         | varchar           | ID товара                                                                      |
| active     | boolean           | Активность                                                                     |
| json       | text              | Объект товара в такой же структуре, как в [импорте через API](../api/index.md) |
| updated_at | timestamp = now() | Дата обновления                                                                |
| synced_at  | timestamp         | Дата обработки                                                                 |

::: warning Дата обновления и синхронизации
В каждой таблице хранится дата обновления со стороны клиента (`updated_at`) и дата синхронизации с REES46 (`synced_at`).
Важно обновлять эту информацию только для тех товаров, которые на самом деле были изменены.
:::

Колонка `active` предназначена для обновления сведений о наличии данных, без их удаления.

При каждой обработке система забирает данные и фильтрует их по колонкам: `updated_at`, `active`, `synced_at`.

Они передаются в API порциями по 2000 штук. Время в колонке `processed_at` обновляется.

::: warning Обратите внимание
1. При каждом обновлении **обязательно** проставлять текущее время **(UTC=0)** в колонке `updated_at` и **НЕ ОБНОВЛЯТЬ** колонку `processed_at`.
2. Если данные в строке не обновлялись, обновлять значение колонки `updated_at` **НЕЛЬЗЯ**.
:::
