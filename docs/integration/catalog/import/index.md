# Общие рекомендации по импорту каталога

## Картинки

Для загрузки изображений товаров система может многократно обращаться к серверу интернет-магазина. Убедитесь, что [IP-адреса платформы](../../extended/subnet.md) внесены в список исключений (белый список) в случае, если на сервере интернет-магазина используется защита от DDoS-атак или любой другой тип блокировки многократных обращений к серверу. В противном случае система REES46 не сможет получить доступ к изображениям товаров, и товары без изображений будут исключены из рекомендаций, поиска и рассылок.

## HTTPS

Все `web push` и `mobile push` оповещения требуют наличия на сайте HTTPS протокола. Триггерные `push` оповещения также требуют ссылок на изображения товаров в https-протоколе. Если ваш сайт не работает на HTTPS, функционал сервиса может быть ограничен.

## Импорт товаров с нулевой ценой

Независимо от выбранного метода импорта, загрузка товаров с нулевой ценой возможна только при включённой настройке, доступной администраторам.

Для её включения вам нужно будет обратиться в службу поддержки.
