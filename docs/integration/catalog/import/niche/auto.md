# Расширение "Автотовары"

```
offer > auto
```

Нишевый алгоритм "Автомобильные товары" предназначен для автоматического распознавания в посетителе потенциального покупателя с определёнными характеристиками: марка и модель авто и используемые автомобильные товары и вывода товарных рекомендаций с учётом этих характеристик.

Для работы алгоритма вам необходимо передавать дополнительные параметры о товарах в секцию `auto`:

- марка и модель авто;
- тип товара;
- тип регулярно покупаемого товара.

::: tip Совет
Даже если вы не будете указывать ни один из вложенных элементов секции `auto`, все равно рекомендуется отметить `offer`, как автотовар, с помощью пустого тега `<auto/>`.
:::


## Совместимость с марками и моделями

```
offer > auto > compatibility
```

Размещается внутри секции `offer > auto` и состоит из одной или нескольких записей совместимости товара с определенными марками и моделями автомобилей:

Пример:

::: code-group
```XML [YML]
 ...
<offer ...>
    ...
    <auto>
        <!-- Марка без модели означает, что товар совместим с любой моделью данной марки -->
        <compatibility brand="BMW" />
        <!-- Марка и модель означают, что товар совместим с этой маркой и моделью -->
        <compatibility brand="Mini" model="Cooper S" />
        <!-- При этом может быть перечислено более одной модели -->
        <compatibility brand="Mini" model="Cooper c" />
    </auto>
</offer>
```

```json [JSON API]
{
  ...,
  "auto": {
    "compatibility": [
      {
        "brand": "BMW"
      },
      {
        "brand": "Mini",
        "model": "Cooper S"
      },
      {
        "brand": "Mini",
        "model": "Cooper One"
      }
    ]
  }
}
```
:::

::: info Совет
Если товар совместим со всеми марками и моделями автомобиля, элементы `compatibility` указывать не нужно.
:::

## Регулярно покупаемый товар

Необязательный элемент.

```
offer > auto > periodic
```

Размещается внутри секции `offer > auto` и сообщает системе, что данный товар может приобретаться с определенной периодичностью.

| Значение параметра | Расшифровка                           |
|--------------------|---------------------------------------|
| 1                  | Товар, который покупают регулярно.    |
| 0                  | Товар, который не покупают регулярно. |

::: tip Лайфхак
Если товар не регулярного потребления, можете просто не указывать этот тег.
:::

Пример:

::: code-group
```XML [YML]
<offer ...>
    <auto>
        ...
        <periodic>1</periodic>
    </auto>
</offer>
```

```json [JSON API]
{
  ...,
  "auto": {
    "periodic": true
  }
}
```
:::


## Идентификатор автомобиля VIN

Необязательный элемент.

```
offer > auto > vds
```

Размещается внутри секции `offer > auto` и представляет из себя одну или несколько записей [VDS](https://ru.wikipedia.org/wiki/%D0%98%D0%B4%D0%B5%D0%BD%D1%82%D0%B8%D1%84%D0%B8%D0%BA%D0%B0%D1%86%D0%B8%D0%BE%D0%BD%D0%BD%D1%8B%D0%B9_%D0%BD%D0%BE%D0%BC%D0%B5%D1%80_%D1%82%D1%80%D0%B0%D0%BD%D1%81%D0%BF%D0%BE%D1%80%D1%82%D0%BD%D0%BE%D0%B3%D0%BE_%D1%81%D1%80%D0%B5%D0%B4%D1%81%D1%82%D0%B2%D0%B0#VDS) - раздела VIN, описывающего детали комплектации транспортного средства:

Пример:

::: code-group
```XML [YML]
<offer ...>
    <auto>
        ...
        <vds>BP8AN5</vds>
        <vds>HH5820</vds>
    </auto>
</offer>
```

```json [JSON API]
{
  ...,
  "auto": {
    "vds": ["BP8AN5", "HH5820"]
  }
}
```
:::
