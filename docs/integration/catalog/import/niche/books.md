# Расширение "Книги"

Нишевый алгоритм "Книги" предназначен для автоматического распознавания в посетителе приверженца определенных авторов, издательств и пр.

Для работы алгоритма вам необходимо передавать дополнительные характеристики товаров:

- автор;
- издатель;
- серия;
- год публикации;
- ISBN.

## Параметры

::: code-group
```XML [YML]
<offer ...>
    <author>Александра Маринина</author>
    <publisher>Эксмо</publisher>
    <series>А. Маринина — королева детектива</series>
    <year>2007</year>
    <ISBN>978-5-699-23647-3</ISBN>
</offer>
```

```json [JSON API]
{
  "author": "...",  // String. Optional.
  "publisher": "...", // String. Optional.
  "series": "...", // String. Optional.
  "year": ..., // Integer. Optional.
  "isbn": [ ... ] // Array of strings. Optional.
} 
```
:::
