# Расширение "Стройматериалы"

```
offer > construction
```

Алгоритм автоматически сегментирует аудиторию на:

- профессиональных строителей;
- розницу в процессе ремонта;
- розницу в подготовке к ремонту.

Дополнительно сегментирует аудиторию на:

- ремонт в квартире или городском помещении;
- ремонт или строительство за городом.

## Регулярно покупаемый товар

```
offer > construction > periodic
```

Необязательный параметр.

| Значение элемента | Расшифровка                                       |
|-------------------|---------------------------------------------------|
| 1                 | Товар, который покупают регулярно (материал)      |
| 0                 | Товар, который не покупают регулярно (инструмент) |

::: info Лайфхак
Если товар не регулярного потребления, можете просто не указывать этот тег.
:::

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <construction>
        <periodic>1</periodic>
    </construction>
</offer>
```

```json [JSON API]
{
  "construction": {
    "periodic": true
  }
} 
```
:::

## Тип товара

```
offer > construction > type
```

Необязательный параметр.

| Значение элемента | Расшифровка           |
|-------------------|-----------------------|
| material          | Строительный материал |
| tool              | Рабочий инструмент    |

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <construction>
        <type>tool</type>
    </construction>
</offer>
```

```json [JSON API]
{
  "construction": {
    "type": "tool"
  }
} 
```
:::

## Товар для загородного ремонта и строительства

```
offer > construction > outdoor
```

Необязательный параметр.

| Значение элемента | Расшифровка                                                           |
|-------------------|-----------------------------------------------------------------------|
| 1                 | Товар, предназначенный только для загородного ремонта и строительства |
| 0                 | Товар для ремонта как за городом, так и в квартирах                   |

::: info Лайфхак
Если товар не только для загородного дома, можете просто не указывать этот тег.
:::

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <construction>
        <outdoor>1</outdoor>
    </construction>
</offer>
```

```json [JSON API]
{
  "construction": {
    "outdoor": true
  }
} 
```
:::

## Тип строительства

```
offer > construction > construction_types
```

Необязательный параметр. Характеризует тип ремонта, для которого предназначен товар. Может иметь несколько вложенных элементов.

| Значение элемента | Расшифровка               |
|-------------------|---------------------------|
| floor             | Для ремонта пола          |
| wall              | Для ремонта стен          |
| ceiling           | Для ремонта потолка       |
| decor             | Для декоративного ремонта |
| outdoor           | Для наружного ремонта     |
| indoor            | Для внутреннего ремонта   |
| roof              | Для ремонта крыши         |

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <construction>
        <construction_types>
            <construction_type>wall</construction_type>
            <construction_type>outdoor</construction_type>
        </construction_types>
    </construction>
</offer>
```

```json [JSON API]
{
  "construction": {
    "construction_types": ["wall", "outdoor"]
  }
} 
```
:::
