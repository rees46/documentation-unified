# Расширение "Косметика и парфюмерия"

```
offer > cosmetic
```

Нишевый алгоритм "Косметика" предназначен для автоматического распознавания в посетителе потенциального покупателя с определёнными характеристиками и предрасположенностью к определённым косметическим и гигиенически средствам, и вывода товарных рекомендаций с учётом этих характеристик.

Для работы алгоритма вам необходимо передавать дополнительные параметры о товарах:

* пол, к которому относится товар;
* объем и тип товара
* дополнительная нишевая информация.

## Пол

```
offer > cosmetic > gender
```

Рекомендуемый элемент. Если у вас нет данных о принадлежности товара к определённому полу `gender`, не указывайте этот элемент. В этом случае данный товару будет присвоено значение "унисекс" и он будет иметь более низкий приоритет в выдаче рекомендаций по сравнению с другими товарами определённого пола.

| Значение элемента | Расшифровка  |
|-------------------|--------------|
| m                 | Мужской      |
| f                 | Женский      |

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <cosmetic>
        <gender>f</gender>
    </cosmetic>
</offer>
```

```json [JSON API]
{
  "cosmetic": {
    "gender": "m"
  }
} 
```
:::


## Гипоаллергенность `hypoallergenic`

Необязательный элемент `hypoallergenic`. Размещается внутри секции `offer > cosmetic`.

| Значение элемента | Расшифровка              |
|-------------------|--------------------------|
| 1                 | Гипоаллергенный товар    |
| 0                 | Товар не гипоаллергенный |

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <cosmetic>
        <hypoallergenic>1</hypoallergenic>
    </cosmetic>
</offer>
```

```json [JSON API]
{
  "cosmetic": {
    "hypoallergenic": true
  }
} 
```
:::

::: info Лайфхак
Если товар не гипоаллергенный, просто не указывайте этот элемент.
:::


## Для кожи

```
offer > cosmetic > skin
```

Секция отвечает за характеристики товара для кожи.

### Использование для частей тела `part`

Необязательный элемент `part`.

| Значение | Расшифровка                        |
|----------|------------------------------------|
| face     | для лица, макияж, средства для рта |
| body     | для тела, духи                     |
| intim    | для интимной гигиены               |
| hand     | для рук                            |
| leg      | для ног                            |

Если товар предназначен для нескольких частей тела, то значения передаются списком `part`.

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <cosmetic>
        <skin>
            <part>face</part>
            <part>body</part>
        </skin>
    </cosmetic>
</offer>
```

```json [JSON API]
{
  "cosmetic": {
    "skin": {
      "part": ["face", "body"]
    }
  }
} 
```
:::


### Использование по типу кожи `type`

Необязательный элемент `type`.

| Значение | Расшифровка     |
|----------|-----------------|
| dry      | сухая           |
| normal   | нормальная      |
| oily     | жирная          |
| comby    | комбинированная |

::: code-group
```XML [YML]
<offer ...>
    ...
    <cosmetic>
        <skin>
            <part>face</part>
            <part>body</part>
            <type>normal</type>
            <type>comby</type>
        </skin>
    </cosmetic>
</offer>
```

```json [JSON API]
{
  "cosmetic": {
    "skin": {
      "part": ["face", "body"],
      "type": ["normal", "comby"]
    }
  }
} 
```
:::


### Использование по состоянию кожи `condition`

Необязательный элемент `condition`.

| Значение   | Расшифровка    |
|------------|----------------|
| dehydrated | обезвоженная   |
| sensitive  | чувствительная |
| problem    | проблемная     |
| fading     | увядающая      |

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <cosmetic>
        <skin>
            <part>face</part>
            <part>body</part>
            <type>normal</type>
            <type>comby</type>
            <condition>sensitive</condition>
            <condition>fading</condition>
        </skin>
    </cosmetic>
</offer>
```

```json [JSON API]
{
  "cosmetic": {
    "skin": {
      "part": ["face", "body"],
      "type": ["normal", "comby"],
      "condition": ["sensitive", "fading"]
    }
  }
} 
```
:::

## Для парфюмерии

```
offer > cosmetic > perfume
```

Секция `perfume` отвечает за характеристики парфюмерии.

### Семейство ароматов `perfume > family`

Обязательный параметр.

| Значение | Расшифровка    |
|----------|----------------|
| floral   | Цветочные ноты |
| oriental | Восточные ноты |
| woody    | Древесные ноты |
| fresh    | Свежие ноты    |

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <cosmetic>
        <perfume>
            <family>woody</family>
        </perfume>
    </cosmetic>
</offer>
```

```json [JSON API]
{
  "cosmetic": {
    "perfume": {
      "family": "woody"
    }
  }
} 
```
:::


### Подгруппы внутри семейства ароматов

Необязательный параметр `perfume > aroma`. Если вы затрудняетесь определить подгруппу, не указывайте ее.

| Отношение к семейству | Значение параметра | Описание               | Комментарий                                                                           |
|-----------------------|--------------------|------------------------|---------------------------------------------------------------------------------------|
| Цветочные ноты        | `fruity_floral`    | Цветочно-фруктовые     |                                                                                       |
| Цветочные ноты        | `floral`           | Классические цветочные | Ароматы свежесрезанных цветов и свежие цветочные                                      |
| Цветочные ноты        | `soft_floral`      | Мягкие цветочные       | Включая альдегиды и пудрово-цветочные                                                 |
| Восточные ноты        | `floral_oriental`  | Теплые цветочные       | Включая гумандско-цветочные (напр. белые цветы) и восточно-цветочные (сладкие специи) |
| Восточные ноты        | `soft_oriental`    | Мягкие восточные       | Включая бензоин и амбру (янтарь)                                                      |
| Восточные ноты        | `oriental`         | Классические восточные | Включая бальзамы и смолы (напр. ладан), а также ваниль                                |
| Древесные ноты        | `woody_oriental`   | Древесно-восточные     | Включая сандал и пачули, теплые запахи                                                |
| Древесные ноты        | `woods`            | Древесные              | Включая ароматные древесные запахи и ветивер                                          |
| Древесные ноты        | `mossy_woods`      | Мшисто-древесные       | Включая шипры, мшистые запахи и амбру (янтарь)                                        |
| Древесные ноты        | `dry_woods`        | Древесные сухие        | Включая кожаные                                                                       |
| Свежие ноты           | `aromatic`         | Ароматики и фужеры     | Свежие ароматы, включая лаванду и ароматные травы                                     |
| Свежие ноты           | `citrus`           | Цитрусовые             | Включая бергамот и другие цитрусовые масла                                            |
| Свежие ноты           | `water`            | Морские                | Включая запах океана и морской воды                                                   |
| Свежие ноты           | `green`            | Зелёные                | Включая гальбан, зеленые ноты и травяные запахи                                       |
| Свежие ноты           | `fruity`           | Фруктовые              | Ягоды и другие фрукты (исключая цитрусовые)                                           |

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <cosmetic>
        <perfume>
            <family>woody</family>
            <aroma>mossy_woods</aroma>
        </perfume>
    </cosmetic>
</offer>
```

```json [JSON API]
{
  "cosmetic": {
    "perfume": {
      "family": "woody",
      "aroma": "mossy_woods"
    }
  }
} 
```
:::

## Регулярно покупаемый товар

```
offer > cosmetic > periodic
```

Необязательный параметр.

| Значение параметра | Расшифровка                           |
|--------------------|---------------------------------------|
| 1                  | Товар, который покупают регулярно.    |
| 0                  | Товар, который не покупают регулярно. |

::: info Лайфхак
Если товар не регулярного потребления, можете просто не указывать этот тег
:::

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <cosmetic>
        <periodic>1</periodic>
    </cosmetic>
</offer>
```

```json [JSON API]
{
  "cosmetic": {
    "periodic": true
  }
} 
```
:::
