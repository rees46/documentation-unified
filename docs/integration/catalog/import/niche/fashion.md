# Расширение "Одежда, обувь"

```
offer > fashion
```

Нишевый алгоритм "Одежда, обувь, аксессуары" предназначен для автоматического распознавания в посетителе потенциального покупателя с определёнными характеристиками: пол и размер (одежды, обуви и т.п.), и вывода товарных рекомендаций с учётом этих характеристик.

Для работы алгоритма вам необходимо передавать дополнительные характеристики товаров:

- пол, к которому относится товар;
- размеры товара и тип размера;
- дополнительная отраслевая информация.

## Пол

```
offer > fashion > gender
```

Рекомендуемый элемент. Если у вас нет данных о принадлежности товара к определённому полу `gender`, не указывайте этот элемент. В этом случае данный товару будет присвоено значение "унисекс" и он будет иметь более низкий приоритет в выдаче рекомендаций по сравнению с другими товарами определённого пола.

| Значение элемента  | Расшифровка  |
|--------------------|--------------|
| m                  | Мужской      |
| f                  | Женский      |

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <fashion>
        <gender>f</gender>
    </fashion>
</offer>
```

```json [JSON API]
{
  "fashion": {
    "gender": "f"
  }
} 
```
:::

## Тип одежды

```
offer > fashion > type
```

| Значение элемента  | Расшифровка                            |
|--------------------|----------------------------------------|
| shoe               | Обувь                                  |
| shirt              | Рубашки, блузки, платья                |
| tshirt             | Футболки                               |
| underwear          | Нижнее белье                           |
| trouser            | Брюки, джинсы, шорты, юбки, купальники |
| jacket             | Куртки, пальто, шубы                   |
| blazer             | Пиджаки, жилеты, джемпера              |
| sock               | Носки                                  |
| belt               | Ремни                                  |
| hat                | Головные уборы                         |
| glove              | Перчатки                               |

::: warning Внимание
Параметр `type` обязателен при использовании параметра `size`. Если размер не указан, вы можете опустить параметр `type`.
:::

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <fashion>
        <gender>f</gender>
        <type>shoe</type>
    </fashion>
</offer>
```

```json [JSON API]
{
  "fashion": {
    "gender": "f",
    "type": "shoe"
  }
} 
```
:::

## Размер одежды

```
offer > fashion > sizes
```

| Тип размерной сетки                                                         | Описание                                     | Пример  |
|-----------------------------------------------------------------------------|----------------------------------------------|---------|
| префикс не требуется или r                                                  | Российская размерная сетка                   | r44, 44 |
| e                                                                           | Европейская размерная сетка                  | e38     |
| префикс не требуется, если размер буквенный, в противном случае - префикс u | Американская / международная размерная сетка | XS, u30 |
| b                                                                           | Английская размерная сетка                   | b6      |
| h                                                                           | Рост (для детских товаров)                   | h89-95  |
| префикс не требуется                                                        | Безразмерный (подходит на всех)              | null    |

::: info Несколько размеров
У одного товара может быть несколько размеров, поэтому размеры передаются списком `size`.

В разных локациях может быть разное наличие разных размеров товаров. Поэтому внутри каждого `size` возможно также указать локации, в которых есть конкретный размер товара.
:::

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <fashion>
        <gender>f</gender>
        <type>shoe</type>
        <sizes>
            <size>e40</size>
            <size>e42</size>
            <size>e44</size>
            <size>e48</size>
            <size value="M">
                <location id="3" />
                <param name="Талия" unit="мм">170</param>
            </size>
        </sizes>
    </fashion>
</offer>
```

```json [JSON API]
{
  "fashion": {
    "gender": "f",
    "type": "shoe",
    "sizes": ["37"]
  }
} 
```
:::

## Цвет одежды

```
offer > fashion > color
```

::: info Важно
У одного товара может быть несколько цветов `color`. Атрибут `picture` может отсутствовать, в этом случае используется основное изображение товара.
:::

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <fashion>
        <gender>f</gender>
        <type>shoe</type>
        <color>red</color>
        <color picture="https://example.com/items/395532-green.jpg">green</color>
    </fashion>
</offer>
```

```json [JSON API]
{
  "fashion": {
    "gender": "f",
    "type": "shoe",
    "colors": [
      {
        "color": "red"
      },
      {
        "color": "green",
        "picture": "https://example.com/items/395532-green.jpg"
      }
    ]
  }
} 
```
:::

## Особенности

```
offer > fashion > feature
```

Необязательный параметр. 

| Значение элемента  | Расшифровка                          |
|--------------------|--------------------------------------|
| pregnant           | Для беременных                       |
| child              | Для детей                            |
| adult              | Для взрослых (значение по умолчанию) |

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <fashion>
        <gender>f</gender>
        <type>shoe</type>
        <feature>pregnant</feature>
    </fashion>
</offer>
```

```json [JSON API]
{
  "fashion": {
    "gender": "f",
    "type": "shoe",
    "feature": "pregnant"
  }
} 
```
:::
