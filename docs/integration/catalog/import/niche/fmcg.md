# Расширение "Товары повседневного спроса"

```
offer > fmcg
```

Алгоритм автоматически определяет регулярно покупаемые клиентом товары и рекомендует им типовые корзины в процессе повторной закупки, повышая средний чек. 

Для работы алгоритма вам необходимо передавать дополнительные данные о товарах:

- товар регулярного потребления;
- тип товара.

## Регулярно покупаемый товар

```
offer > fmcg > periodic
```

Необязательный элемент.

| Значение элемента | Расшифровка                          |
|-------------------|--------------------------------------|
| 1                 | Товар, который покупают регулярно    |
| 0                 | Товар, который не покупают регулярно |

::: info Лайфхак
Если товар не регулярного потребления, можете просто не указывать этот тег.
:::

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <fmcg>
        <periodic>1</periodic>
    </fmcg>
</offer>
```

```json [JSON API]
{
  "fmcg": {
    "periodic": true
  }
} 
```
:::


## Тип товара

```
offer > fmcg > type
```

Необязательный элемент.

| Значение элемента | Расшифровка                         |
|-------------------|-------------------------------------|
| food              | Продукты питания, фермерские товары |
| chemicals         | Товары бытовой химии                |
| hygiene           | Средства гигиены                    |
| supplies          | Канцелярские товары                 |
| child             | Детские товары                      |

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <fmcg>
        <periodic>1</periodic>
        <type>food</type>
    </fmcg>
</offer>
```

```json [JSON API]
{
  "fmcg": {
    "periodic": true,
    "type": "food"
  }
} 
```
:::


## Гипоаллергенность

```
offer > fmcg > hypoallergenic
```

Необязательный элемент.

| Значение элемента | Расшифровка              |
|-------------------|--------------------------|
| 1                 | Гипоаллергенный товар    |
| 0                 | Товар не гипоаллергенный |

::: info Лайфхак
Если у вас нет данных о гипоаллергенности товара, не указывайте этот элемент. По-умолчанию товар считается не гипоаллергенным.
:::

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <fmcg>
        <periodic>1</periodic>
        <type>food</type>
        <hypoallergenic>1</hypoallergenic>
    </fmcg>
</offer>
```

```json [JSON API]
{
  "fmcg": {
    "periodic": true,
    "type": "food",
    "hypoallergenic": true
  }
} 
```
:::
