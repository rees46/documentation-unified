# Нишевые параметры

Нишевые параметры (расширения) позволяют добавить техническую информацию к офферам, которая усиливает эффект алгоритмов персонализации. Эти свойства не обязательны к заполнению, но в некоторых вертикалях значительно увеличивают дополнительную выручку от товарных рекомендаций, поиска, листинга товаров и триггерных рассылок.
