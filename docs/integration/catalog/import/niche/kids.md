# Расширение "Товары для детей"

```
offer > child
```

::: info Совет
Даже если вы не будете указывать ни один из вложенных элементов секции `child`, все равно рекомендуется отметить `offer`, как детский, с помощью пустого тега `<child/>`.
:::

Нишевый алгоритм "Детские товары" предназначен для автоматического распознавания в посетителе потенциального покупателя детских товаров с определёнными характеристиками ребёнка: пол, возраст, размер (одежды, обуви и т.п.), предрасположенность определённым косметическим и гигиенически средствам, а также продуктам питания, и вывода товарных рекомендаций с учётом этих характеристик.

Для работы алгоритма каждый товар должен содержать дополнительные параметры, указываемые в секции `child` внутри `offer`:

* пол, к которому относится товар;
* вилка возрастов, если товар предназначен для детей младше 2-х лет;
* дополнительная отраслевая информация, передаваемая в соответствующих самостоятельных секциях:
    * одежда (секция `fashion`)
    * косметика (секция `cosmetic`)
    * товары регулярного спроса (секция `fmcg`)

## Пол 

``` 
offer > child > gender
```

Рекомендуемый элемент. Если у вас нет данных о принадлежности товара к определённому полу `gender`, не указывайте этот элемент. В этом случае данный товару будет присвоено значение "унисекс" и он будет иметь более низкий приоритет в выдаче рекомендаций по сравнению с другими товарами определённого пола.

| Значение элемента | Расшифровка |
|-------------------|-------------|
| m                 | Мужской     |
| f                 | Женский     |

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <child>
        <gender>f</gender>
    </child>
</offer>
```

```json [JSON API]
{
  "child": {
    "gender": "m"
  }
} 
```
:::


## Тип товара

``` 
offer > child > type
```

Необязательный элемент `type`.

| Значение параметра | Расшифровка                                                                 |
|--------------------|-----------------------------------------------------------------------------|
| toy                | Игрушки                                                                     |
| education          | Развивающие игрушки, конструкторы                                           |
| nappy              | Подгузник                                                                   |
| furniture          | Предметы мебели                                                             |
| school             | Школьные принадлежности                                                     |
| transport          | Средства транспортировки (коляски, автокресла, самокаты, велосипеды и т.п.) |

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <child>
        <gender>f</gender>
        <type>toy</type>
    </child>
</offer>
```

```json [JSON API]
{
  "child": {
    "gender": "m",
    "type": "toy"
  }
} 
```
:::


## Возраст

``` 
offer > child > age
```

Необязательный элемент `age > min`, `age > max`. Передается минимальный и максимальный возраст для товаров, предназначенных для детей младше 2-х лет. Для товаров одного возраста параметры `min` и `max` должны быть равнозначными.

| Возраст   | Значение |
|-----------|----------|
| 1-3 мес   | 0.25     |
| 4-6 мес   | 0.5      |
| 7-9 мес   | 0.75     |
| 10-12 мес | 1        |
| 13-15 мес | 1.25     |
| 16-18 мес | 1.5      |
| 19-21 мес | 1.75     |
| 22-24 мес | 2        |
| 3 года    | 3        |
| 4 года    | 4        |
| ...       | и т.д.   |

Пример для товаров с диапазоном возрастов:

::: code-group
```XML [YML]
<offer ...>
    ...
    <child>
        <gender>f</gender>
        <type>toy</type>
        <age>
          <min>0.5</min>
          <max>1</max>
        </age>
    </child>
</offer>
```

```json [JSON API]
{
  "child": {
    "gender": "m",
    "type": "toy",
    "age": {
      "min": 3,
      "max": 7
    }
  }
} 
```
:::


## Связь нескольких нишевых секций

### Пример связанных секций `child` и `fashion`

Если детский товар является предметом одежды, то всю дополнительную информацию о товаре необходимо передавать в соответствующей секции `fashion`.

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <child>
        <gender>f</gender>
        <type>toy</type>
        <age>
          <min>0.5</min>
          <max>1</max>
        </age>
    </child>
    <fashion>
        <type>jacket</type>
        <sizes>
          <size>h80-82</size>
          <size>h83-85</size>
          <size>h86-88</size>
        </sizes>
    </fashion>
</offer>
```

```json [JSON API]
{
  "child": {
    "gender": "m",
    "type": "toy",
    "age": {
      "min": 3,
      "max": 7
    }
  },
  "fashion": {
    "type": "jacket",
    "sizes": ["h80-82", "h80-85", "h80-88"]
  }
} 
```
:::


### Пример связанных секций `child` и `cosmetic`

Если детский товар относится к косметике и средствам гигиены, то всю дополнительную информацию о товаре необходимо передавать в соответствующей секции `cosmetic`.

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <child>
        <gender>f</gender>
        <type>toy</type>
        <age>
          <min>0.5</min>
          <max>1</max>
        </age>
    </child>
    <cosmetic>
        <hypoallergenic>1</hypoallergenic>
        <skin>
            <part>face</part>
            <part>body</part>
            <type>normal</type>
            <type>oily</type>
            <condition>sensitive</condition>
            <condition>problem</condition>
        </skin>
    </cosmetic>
</offer>
```

```json [JSON API]
{
  "child": {
    "gender": "m",
    "type": "toy",
    "age": {
      "min": 3,
      "max": 7
    }
  },
  "cosmetic": {
    "hypoallergenic": true,
    "skin": {
      "part": ["face", "body"],
      "type": ["normal", "oily"],
      "condition": ["sensitive", "problem"]
    }
  }
} 
```
:::


### Пример связанных секций `child` и `fmcg`

Если детский товар является товаром регулярного потребления, то всю дополнительную информацию о товаре необходимо передавать в соответствующей секции `fmcg`.

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <child>
        <gender>f</gender>
        <type>toy</type>
        <age>
          <min>0.5</min>
          <max>1</max>
        </age>
    </child>
    <fmcg>
        <periodic>1</periodic>
        <type>food</type>
    </fmcg>
</offer>
```

```json [JSON API]
{
  "child": {
    "gender": "m",
    "type": "toy",
    "age": {
      "min": 3,
      "max": 7
    }
  },
  "fmcg": {
    "periodic": true,
    "type": "food"
  }
} 
```
:::
