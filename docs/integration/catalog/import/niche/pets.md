# Расширение "Товары для животных"

```
offer > pets
```

Алгоритм автоматически определяет домашних питомцев покупателя и рекомендует те товары, которые им подходят.

Для работы алгоритма вам необходимо передавать дополнительные параметры о товарах:

- тип животного, к которому относится товар;
- регулярность покупок товаров;
- возраст питомца.

## Тип животного

```
offer > pets > pet_type
```

Рекомендуемый элемент. Если животное не относится ни к одному из указанных видов, не указывайте параметр.

| Значение элемента | Расшифровка |
|-------------------|-------------|
| dog               | Собака      |
| cat               | Кошка       |
| bird              | Птицы       |
| fish              | Рыбки       |

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <pets>
        <pet_type>cat</pet_type>
    </pets>
</offer>
```

```json [JSON API]
{
  "pets": {
    "pet_type": "cat"
  }
} 
```
:::


## Порода животного

```
offer > pets > breed
```

Необязательный элемент. Указывайте код породы животного латиницей, если товар относится к конкретной породе животного. Если товар относится к широкому перечню пород, не используйте это поле.

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <pets>
        <breed>dvor terrier</breed>
    </pets>
</offer>
```

```json [JSON API]
{
  "pets": {
    "breed": "dvor terrier"
  }
} 
```
:::

## Размер животного

```
offer > pets > pet_size
```

Необязательный элемент. Указывайте относительный размер животного, если товар имеет отношение к размеру животного. Например, мешок корма для большой собаки.

| Значение элемента | Расшифровка |
|-------------------|-------------|
| small             | Маленькое   |
| medium            | Среднее     |
| large             | Большое     |

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <pets>
        <pet_size>large</pet_size>
    </pets>
</offer>
```

```json [JSON API]
{
  "pets": {
    "pet_size": "large"
  }
} 
```
:::

## Регулярно покупаемый товар

```
offer > pets > periodic
```

Необязательный параметр.

| Значение элемента | Расшифровка                          |
|-------------------|--------------------------------------|
| 1                 | Товар, который покупают регулярно    |
| 0                 | Товар, который не покупают регулярно |

::: info Лайфхак
Если товар не регулярного потребления, можете просто не указывать этот тег.
:::

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <pets>
        <periodic>1</periodic>
    </pets>
</offer>
```

```json [JSON API]
{
  "pets": {
    "periodic": true
  }
} 
```
:::

## Возраст питомца

```
offer > pets > pet_age
```

Необязательный элемент.

| Значение элемента | Расшифровка                                       |
|-------------------|---------------------------------------------------|
| young             | Котята, щенята, свинята и прочие молодые животные |
| middle            | Животные в полном рассвете сил                    |
| old               | Старые животные                                   |

Пример:

::: code-group
```XML [YML]
<offer ...>
    ...
    <pets>
        <pet_age>old</pet_age>
    </pets>
</offer>
```

```json [JSON API]
{
  "pets": {
    "pet_age": "old"
  }
} 
```
:::
